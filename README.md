# Máscara de Voz

App web para transformar a voz em tempo real em vozes de criaturas de RPG (velha, drow, goblin, hobgoblin, devorador de mentes, minotauro, duergar). Abra no Chrome do celular pelo link do GitHub Pages, conecte a caixa Bluetooth e toque em "Ligar microfone".

Tudo roda no próprio celular, sem IA e sem custo. As vozes ficam salvas no navegador.
